全局配置

代理服务的鉴权、默认模型与 Key 自动禁用阈值。

代理鉴权 Token proxy_auth_token

启用后，Claude Code 需要在请求中携带 Token 才能访问代理服务。

配置后请求需携带 Authorization: Bearer token 或 X-API-Key 头

默认客户端模型 default_client_model

未指定 model 参数时使用的默认模型。

Key 自动禁用阈值 key_max_errors

API Key 累计错误达到此次数后自动禁用（需开启自动禁用功能）。0 或不填则使用环境变量 KEY_MAX_ERRORS 的值（默认 5）。
